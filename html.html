HTML gives a website its structure

Before you worry about colors or animations, you need content. HTML tells your browser what that content is.

Beginner-friendly No experience needed
< / >
01 / BUILDING BLOCKS

Think in elements

HTML stands for HyperText Markup Language. It is not a programming language in the same sense as JavaScript. Instead, it uses elements to describe pieces of a page. An opening tag usually marks where an element starts, and a closing tag marks where it ends.

For example, a heading tells readers what a section is about, a paragraph holds an explanation, and a link leads to another page. When the structure is clear, the page is easier for people and assistive technologies to understand.

MY-FIRST-PAGE.HTML HTML 
<h1>Welcome to my first page</h1>
<p>I am learning how websites work.</p>
<a href="https://example.com">Visit a website</a>

Notice the pattern: the <h1> element is a main heading, <p> holds a paragraph, and <a> creates a link. The href attribute tells the browser where that link should go.

02 / THE FULL PAGE

What an HTML file looks like

INDEX.HTML HTML 
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My First Website</title>
  </head>
  <body>
    <h1>Hello, web!</h1>
    <p>This page started as a text file.</p>
  </body>
</html>

The <head> stores information about the document, such as its title. The <body> holds the content visitors actually see. Save this as index.html, then open it in your browser to preview it.

03 / TRY IT YOURSELF

Your first tiny challenge

  1. Create an HTML file Use a plain-text editor and name the file index.html.
  2. Add your own content Write a heading about something you enjoy and a paragraph explaining why.
  3. Open it in a browser Double-click the file or open it with your favorite browser.
  4. Make one change Edit the heading, save the file, and refresh the page.
Remember

HTML describes what the content is. The next lesson shows how CSS changes how that content looks.
