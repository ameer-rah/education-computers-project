What happens when you open a website

Typing an address into your browser may feel instant, but a lot happens behind the scenes. Here is the simple version.

Beginner-friendly No experience needed

01 / FROM CLICK TO PAGE

The journey of a web page

Your browser is the app you use to explore the web. A server is a computer or service that stores and delivers website files. When you follow a link, the browser requests information from a server, receives a response, and uses that information to display the page.

01 Your browser Requests a page
Request → ← Response
02 Web server Returns site files

You can think of the address as directions to a destination, the browser as the visitor, and the server as the place that sends the requested content. The comparison is not perfect, but it helps explain why a website needs to be published somewhere before other people can visit it.

02 / WHO DOES WHAT

Front end and back end

FRONT END

What you see and use

The front end is the part shown in the browser: the navigation, buttons, page layout, and text. HTML, CSS, and JavaScript are its basic building blocks.

BACK END

What supports the experience

The back end can handle things such as saved accounts, stored information, and requests to a database. Not every simple website needs one.

For example, a course-planning application may display schedules and buttons on the front end while using a server and database to retrieve course information. This is one reason web development combines visual design with logical problem-solving.

03 / QUICK VOCABULARY

Four words worth knowing

URL
The web address that identifies a page or resource.
Domain
The memorable name people type to find a site.
Hosting
The service that makes website files accessible online.
Responsive design
A layout that adjusts to different screen sizes.

Open a website you visit often. Which parts are visible interface elements? Which features might need information stored somewhere else?
